## 💬 Community Features & Moderation

- **Comments** on each blog post are powered by [Utterances](https://utteranc.es/) and live as GitHub issues in this repository.
  - Open the matching issue (linked directly from the embedded widget) to hide, lock, or delete any reply.
  - Removing a comment immediately removes it from the published site because GitHub Pages serves the widget in realtime.
- **Likes** are tracked via [countapi.xyz](https://countapi.xyz) per-post counters with local browser guards to reduce spam.
  - Reset a counter by visiting `https://api.countapi.xyz/set/blackframeai.blog/<post-key>?value=0` while signed in — e.g. replace `<post-key>` with `birth-of-vibe-coding`.
  - The client only stores a boolean flag in `localStorage` to stop repeat likes from the same browser; no personal data is collected.

## 🛡️ Security Notes

- The public site is completely static and served from GitHub Pages, limiting the attack surface to vetted third-party embeds (Utterances + countapi).
- External links open in new tabs with `rel="noopener noreferrer"` to prevent tab-nabbing and keep referrer leakage minimal.
- Audit the repository history for any secrets before publishing; none are committed by default.
- If deeper restrictions are required, enable GitHub Pages content security policies through a CDN or service worker to pin approved script origins (`utteranc.es` and `api.countapi.xyz`).

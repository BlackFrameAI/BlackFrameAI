## 🛡️ Security Notes

- The public site is completely static and served from GitHub Pages, limiting the attack surface to the vetted Utterances comment embed.
- External links open in new tabs with `rel="noopener noreferrer"` to prevent tab-nabbing and keep referrer leakage minimal.
- Audit the repository history for any secrets before publishing; none are committed by default.
- If deeper restrictions are required, enable GitHub Pages content security policies through a CDN or service worker to pin approved script origins (e.g., `utteranc.es`).

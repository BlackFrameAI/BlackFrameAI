# Documentation Archive

This directory collects internal research notes, prototypes, and experiment logs that are not part of the production website.

- Keep materials in portable text-friendly formats such as Markdown, plain text, or JSON.
- Organize content by sprint or system component (for example, `phase-02/` or `render-pipeline/`) to simplify future reference.
- Redact private information before sharing any excerpts outside the team.
- Add an `INDEX.md` file to each subfolder summarizing its contents so other contributors can quickly understand what lives there.

The site generator ignores this directory by default, so nothing here becomes public unless a page links to it intentionally.

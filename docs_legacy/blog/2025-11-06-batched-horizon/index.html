Why this day matters

Day 18 is the moment Codex proves the procedural stack can police itself: batched drawing, unattended test pilots, and registry-backed overlays now share one evidence trail, so reviewers can audit how the engine stays stable without human spotters.Engine Devlog · 2025-06-27

Setup

The vault opens with RenderSystem still falling back to `bindDefaultUiState()` mid-draw to recover missing VAOs, forcing manual recovery paths and polluting the logs whenever overlays drifted off the happy path.Engine Devlog · 2025-06-27

Gameplay suffered the same friction—automated runs didn’t exist yet, menu rendering triggered OpenGL warnings, and offscreen actors kept drawing because nothing gated visibility.Game Devlog · 2025-06-27

Breakthroughs

Codex rewired the renderer to batch every procedural shape, then introduced `RenderSystem::isWorldVisible` so culling happens before any overlay or gameplay system wastes cycles on offscreen sprites.Engine Devlog · 2025-06-27Game Devlog · 2025-06-27

The day also shipped a `--autotest` harness that drives the player randomly while scroll-wheel zoom and sprite scaling keep the camera honest, letting overnight runs validate the new pipeline without babysitting.Engine Devlog · 2025-06-27Game Devlog · 2025-06-27

Finally, RenderSystem now owns UI state: `bindDefaultUiState()` wraps every overlay, `validateUiState` asserts when bindings drift, and the new `ProceduralSpriteRegistry` gives gameplay managers a single source of truth for sprite data and throttled warnings.Engine Devlog · 2025-06-27Game Devlog · 2025-06-27

Failures & Fixes

Recovering lost GL state exposed how fragile the overlay path remained, so Codex instrumented `validateUiState` in every render and taught StatsRenderSystem to rebind defaults before returning control, eliminating the runaway warning spam.Engine Devlog · 2025-06-27

On the game side, the team patched MainMenuScene to bind the correct UI state, restored the default overlay stack, and throttled warnings so a single bad draw no longer floods runtime logs.Game Devlog · 2025-06-27

Next Steps

With the registry and batched renderer live, the evening logs queue RenderSystem to manage overlay flushes and StatsRenderSystem to preserve bindings across multi-window stats views, keeping pressure on the new automation loops to surface any regression early.Engine Devlog · 2025-06-27Game Devlog · 2025-06-27

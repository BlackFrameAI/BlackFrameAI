# Hub UI (Public Summary)

## Overview
The hub interface introduces narrative, progression, and social systems between runs. This public
note emphasizes goals and presentation themes while omitting internal unlock logic and scripting
hooks.

## Focus Areas
- Offer clear navigation between hub services (vendors, narrative beats, challenges) without exposing
  backend state machines.
- Reflect player progression and reputation through adaptable visual cues.
- Leave room for seasonal or event-based panels that can be slotted in without code changes.

## Redaction Notes
Detailed vendor alignment rules, crafting recipes, and terminal integrations were removed. See the
private backup for implementation specifics when contributing to internal builds.

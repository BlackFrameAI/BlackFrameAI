# Global UI (Public Summary)

## Overview
The global UI set covers menus and overlays that persist outside of individual encounters. Detailed
flowcharts and transition states have been withheld from this publication.

## Experience Goals
- Provide a reliable pause and options surface that can be invoked from any supported mode.
- Maintain visual continuity with the broader theme system while avoiding spoilers for unreleased
  features.

## Redaction Notes
Menu transition logic, legacy overlay removal notes, and startup sequencing have been removed. Use
this summary as a guide to the high-level purpose of the global interface suite.

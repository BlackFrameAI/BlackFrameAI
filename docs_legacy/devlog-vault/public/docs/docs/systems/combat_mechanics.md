# Combat Mechanics (Public Summary)

This overview captures the major combat features planned for the project while omitting implementation-specific values or formulas.

## Core Combat Systems

- Eight-directional movement with stamina-aware sprinting and evasive maneuvers.
- Primary and secondary equipment slots supported by additional ability channels for narrative powers.
- Targeted, area, and combo-style attacks that build on the modular action framework.

## Damage & Scaling

- Scaling draws from player alignment, enemy archetypes, encounter modifiers, and world-state hooks.
- Passive abilities adjust outgoing or incoming damage according to alignment thresholds defined in data assets.

## Combat Events

- Large-scale psychic or environmental events that reshape encounters.
- Alignment-based triggers that alter enemy behavior or player abilities.
- Wave structures for climactic battles.

## Planned Enhancements

- Data-driven passives loaded from external descriptors.
- Alignment-triggered bonuses that respond to evolving story states.
- Environmental interactions such as destructible props and hazard fields.

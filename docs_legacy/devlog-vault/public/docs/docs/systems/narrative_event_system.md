# narrative_event_system.md

The **NarrativeEventSystem** handles story events triggered by gameplay. References to privileged scripts or data locations have been replaced with [REDACTED].

- **Questline triggers** unlock passive tree nodes when specific events occur.
- **Betrayal triggers** fire when faction reputation drops below a threshold.
- **Faith triggers** activate once the player's Faith reaches a target value.

Events can execute scripts and are only fired once. Consult the modularization tracker ([REDACTED]) for the system's status.

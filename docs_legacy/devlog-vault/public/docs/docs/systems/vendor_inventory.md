# Vendor Inventory System (Public Summary)

## Overview
The vendor inventory system governs which items appear for purchase in different contexts. This
summary covers intent and fairness considerations while removing sensitive weighting logic and data
schemas.

## Key Principles
- Curate item pools based on player progress and narrative context without exposing raw reputation or
  alignment formulas.
- Allow designers to tag items for themed rotations and special events.
- Ensure that randomness feels fair while still supporting surprise moments.

## Redaction Notes
Detailed probability curves, data structure layouts, and hooks into other progression systems were
removed. Refer to the archived document for engine integration specifics when working inside the
studio.

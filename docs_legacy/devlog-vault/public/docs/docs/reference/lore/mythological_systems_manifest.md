# Mythological Systems Manifest — Lore Focus

This document provides a sanitized overview of narrative myth sources used for Codex lore development. Restricted names, private concordances, and esoteric correspondences are omitted.

---

## Pantheon Archetypes
- **Source Category:** Public myth encyclopedias and open lecture series discussing deity roles.
- **Shared Data:** Alignment themes, conflict dynamics, and symbolism frameworks for major pantheon families.
- **Withheld Data:** Initiatory rites, temple registries, and confidential genealogies.

## Mythic Geography & Realms

Why this day matters

Day 11 documents Codex wiring the studio cockpit. Multi-window orchestration, telemetry routing, and resilient checkpoints now live inside the same evidence trail, proving the agent can coordinate screens, sensors, and saves without human babysitting.

Setup

The vault opens with the multi-display backlog we have ignored since the render bring-up: extra windows existed on paper, yet the engine only ever drove the primary surface and left the rest as placeholders.Engine Devlog · 2025-06-21 Until we solved presentation centrally, Vulkan, DX12, and Metal experiments risked trampling each other’s swapchains. The same log shows SaveSystem still reporting corrupt files in the wild, so failed writes could haunt the next run.Engine Devlog · 2025-06-21

Gameplay pressure was no lighter. The game log reminded us that telemetry had to be portable—combat and hub systems needed the same packets whether sensors were online or sourced from archival JSON.Game Devlog · 2025-06-20 Meanwhile StageManager still lacked cadence fields, overlays overlapped, and checkpoints ignored inventory timers.Game Devlog · 2025-06-21

Breakthroughs

Codex started by turning MultiDisplayManager into the presentation conductor. Displays now load from game/assets/config/display.json or a --display-config override, a new --single-window flag simplifies debug boots, and RuntimeLauncher packages common flag sets for operators.Engine Devlog · 2025-06-20Engine Devlog · 2025-06-21 With presentation now centralized, render backends stop swapping buffers directly, the stats window gains a dedicated RenderSystem, and Codex can experiment with the new DirectX and Metal stubs without touching the main loop.Engine Devlog · 2025-06-20

The second win is telemetry cohesion. TelemetryManager now unifies satellite feeds, offline JSON captures, and fresh HILInterface packets before exposing the stream to the Game layer.Engine Devlog · 2025-06-20 Gameplay consumes the same bus to fuel hub dashboards and combat rehearsals, meaning we can rehearse a sector siege even if the live sensors are cold.Game Devlog · 2025-06-20

Finally, resilience caught up to ambition. SaveSystem now renames corrupted slots instead of overwriting them, serializes inventory and ability cooldowns, and restores the same payload on load.Engine Devlog · 2025-06-21 Stage definitions gained duration, spawn, and powerup intervals while overlays can anchor to any corner, giving Codex deterministic layouts each time a checkpoint replays.Engine Devlog · 2025-06-21Game Devlog · 2025-06-21

Failures & Fixes

Centralizing displays unearthed brittle edges. MultiDisplayManager needed a fallback when configs were missing and a quick escape hatch for single-window runs, both of which landed before the day closed.Engine Devlog · 2025-06-21 We also hit recursion in MemoryTracker while allocating the default context and patched it with raw std::malloc plus stack-overflow guards to keep diagnostics online.Engine Devlog · 2025-06-21

On the gameplay side we discovered our layouts could still collide when JSON failed to load. GameUIManager now falls back to built-in positions, logs the failure, and StageManager warns when definitions are missing so we never boot into an empty run without an alert.Game Devlog · 2025-06-21

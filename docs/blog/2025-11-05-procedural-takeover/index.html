Procedural Takeover, Day 17 Codex Locks the HUD to Bind Defaults

  • bindDefault2DState and bindDefaultUiState now guard every overlay render, forcing Codex to reset GL state before UI draws and eliminating the stray VAO spam.Engine Devlog · 2025-06-26Game Devlog · 2025-06-27

  • Legacy texture and audio pipelines are gone; SynthEngine and shader-only resources pair with ProceduralUISprite migrations to reclaim the HUD from placeholders.Engine Devlog · 2025-06-26Game Devlog · 2025-06-26
Why this day matters

Day 17 captures Codex proving the procedural stack can police itself. The agent welded in GL bind defaults, throttled telemetry, and stripped dead loaders so our HUD and instrumentation survive long autonomous runs without human babysitting.

Setup

We entered the day with brittle GL hygiene. Every overlay carried its own VAO/VBO tweaks, and when Codex forgot to rewind state the logs exploded with invalid handle warnings.Engine Devlog · 2025-06-26 The game log shows the same tension: overlays still relied on procedural sprites without a shared reset, so HUD migrations stalled behind manual fixes.Game Devlog · 2025-06-26

Diagnostics were no better. With debug prints always on, both the engine and StatsRenderSystem flooded captures, masking signal when we needed it most.Engine Devlog · 2025-06-26 And as long as TextureResource and AudioManager lingered, procedural pipelines had to preserve legacy loaders just to keep builds linking.Engine Devlog · 2025-06-26

Breakthroughs

Codex answered by standardizing state recovery. bindDefault2DState now rewires the rect VAO and shader after overlay setup, and UI widgets call it before rendering, guaranteeing a clean GL baseline for the next system.Engine Devlog · 2025-06-26 The companion bindDefaultUiState wraps drawRect, so even fallback geometry routes through the same guardrails.Engine Devlog · 2025-06-26

Runtime visibility followed suit. The logger respects a configurable level, exposes a --debug flag, and throttles verbose overlays to once per minute, letting us run silent by default while preserving forensic depth on demand.Engine Devlog · 2025-06-26

With the pipeline stabilized, Codex finally cut the rot. TextureResource, stb_image, AudioManager, and stb_vorbis exited the build, leaving SynthEngine to own soundscapes and ResourceSystem to focus on shader programs.Engine Devlog · 2025-06-26 HUD elements marched toward ProceduralUISprite, and PlayerStatusOverlay led the migration with animated state that no longer depends on placeholders.Game Devlog · 2025-06-26

Failures & Fixes

Enforcing bind defaults exposed overlays that still mutated GL state after draws. Codex documented the rule, patched stragglers, and wired UIManager to update text sprites every frame so hover states no longer left stale bindings.Engine Devlog · 2025-06-26

HUD migrations also surfaced asset debt—the example terrain and placeholder text renderer baked in assumptions from the retired pipeline. Removing them unlocked clean ProceduralSprite registrations for every enemy archetype and kept the registry authoritative.Game Devlog · 2025-06-26

Next Steps

The bind-default helpers now guard the render path, but June 27’s log reminds us the game still leans on RenderSystem.endFrame for state cleanup. The next sprint pushes Codex to finish the ProceduralUISprite conversion and let the HUD live entirely on the engine-managed bind rails.Game Devlog · 2025-06-27 Once overlays are native, we can reintroduce the archived panels without resurrecting legacy loaders.

Why this day matters

Day 13 shows Codex welding the visual stack and the simulation spine together. Sprite parameters, typography, and network replay now share one evidence trail, so art direction and deterministic sync finally move in the same stride.

Setup

We entered the shift with procedural sprites still carrying bespoke parameter structs. The engine log calls out the migration pressure—frames now need the unified SpriteParams bundle—while the game log proves every factory adopts the same rotation, scale, and tint defaults so modules no longer diverge.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

Typography posed the second constraint. HUD overlays and buttons were still rendered with stb_easy_font, and the game log called for a Game Over scene that matched our procedural aesthetic—forcing Codex to land a vector font pipeline and ProceduralUI helpers instead of another placeholder pass.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

The last blocker lived in the simulation spine. Engine work wired a NetworkSimulationManager and even opened the port, yet the game still had to drive it frame-by-frame while StageManager, SpaceManager, and ParticleManager shifted from placeholder shapes to animated procedural effects that reflect live telemetry.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

Breakthroughs

Codex refactored ProceduralSpriteFrame to merge every draw-time parameter into SpriteParams, exposing rotation, scale, tint, and animation time to both engine tooling and gameplay factories. The game log confirms character modules, pickups, and FX helpers all adopt those defaults, removing the hand-tuned lambda math that previously desynced armor palettes and slash trails.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

A minimal vector font renderer arrived next. The engine now exposes drawTextScreen while HUD overlays and buttons switch to the scalable glyph set; ProceduralUI helpers ride the same path so every widget inherits vector typography. Gameplay closes the loop by shipping a Game Over scene that leans entirely on the new font stack instead of the pixelated fallback.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

On the simulation side, Engine now instantiates NetworkSimulationManager during startup and exposes the instance to the Game, complete with a live port binding and telemetry documentation. The game loop immediately consumes it, replicating player position, reconnecting HIL, and reacting to inbound packets so the same system drives co-op rehearsals and powerup triggers.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

Stage and space rendering levelled up alongside networking. Engine authors SpaceVisuals with procedural ships and a star map, while the game’s StageManager, EnemyVisuals, PickupVisuals, and EffectSprites replace every placeholder primitive with animated geometry that refreshes each stage and pulses with telemetry-fed fleet positions.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

Failures & Fixes

The day’s cleanup focused on the remnants of our texture era. Enemy and powerup structs still held legacy texture handles, blocking procedural variants from hot-swapping frames. Engine stripped those members, stored live ProceduralSpriteInstance data instead, and the game managers followed by removing the old handles so rendering relies solely on procedural sprites.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

Networking demanded similar triage. Save loads previously forgot to restore the network frame or HIL session, leaving clients desynced after a checkpoint. Engine now serializes the frame alongside physics state while the game layer reconnects interfaces and keeps player replication running each tick, preventing ghost inputs when a session resumes.Engine Devlog · 2025-06-22Game Devlog · 2025-06-22

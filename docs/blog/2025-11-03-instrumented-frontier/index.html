Setup

The day opened with a sweep across the render stack. Codex now refuses to draw an overlay unless its shader program, VAO, and VBO all validate, logging a warning instead of spraying undefined behavior when IDs go missing.Engine Devlog · 2025-06-24 Stats windows inherited that discipline—each pass captures resource IDs, vertex counts, and even falls back to placeholder frame timing so the diagnostics stay readable on empty buffers.Engine Devlog · 2025-06-24

RenderSystem also negotiates a debug OpenGL context, enabling GL_KHR_debug callbacks as soon as the driver offers them, so mis-bound state surfaces immediately instead of hiding behind frame captures.Engine Devlog · 2025-06-24

Breakthroughs

Instrumentation moved from logs to visuals. The anchor system gained a true center option plus four edge-centered anchors, all driven from layout files, while AnchorDebugOverlay can be toggled to paint every anchor the renderer knows about.Engine Devlog · 2025-06-24 Bounding boxes, adjustable HUD opacity, and a grayscale post-process tie into the same debug mode, which means UI drift is now a visible artifact, not a guess.Engine Devlog · 2025-06-24

On the gameplay side, startup logs now enumerate which sprites and systems register successfully, flagging absent managers and null dependencies before the first frame advances.Game Devlog · 2025-06-24 Those traces combine with runtime waveform summaries from SynthEngine to prove audio scaffolding boots alongside visuals.Game Devlog · 2025-06-24

Failures & Fixes

More telemetry meant we finally saw how often layouts were missing data. Codex patched GameUIManager::LoadLayout so every bad field logs the failure and gracefully falls back to default positions instead of leaving overlays orphaned offscreen.Engine Devlog · 2025-06-24Game Devlog · 2025-06-24 F10 now guards the most verbose draw logging so RenderSystem can spill per-primitive details when investigators need them without saturating normal runs.Engine Devlog · 2025-06-24

Next Steps

With ccache and unity builds wired into CMake presets, we can iterate on instrumented windows faster, but tomorrow’s push is to stream the same telemetry into secondary displays by default.Engine Devlog · 2025-06-24 The DebugController already blocks stray inputs and exposes hotkeys for layout probes; the next sprint turns those toggles into shared studio presets so every seat boots with the same verified frontier.Engine Devlog · 2025-06-24Game Devlog · 2025-06-24

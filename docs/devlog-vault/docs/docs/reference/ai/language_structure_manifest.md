# Language Structure Reference Manifest

This manifest enables Codex to simulate spoken and written languages using real-world linguistic principles. It supports the procedural generation of dialects, alien scripts, symbol-sound relationships, and cross-cultural phonemic patterns.

---

##  Phonetics & Phonology

**Name:** *IPA Chart (International Phonetic Alphabet)*  
**Type:** Linguistic Reference Chart  
**URL:** https://www.internationalphoneticalphabet.org/ipa-charts/ipa-symbols-chart-complete/  

**Use:** Provides standardized sound symbols for every phoneme. Codex can use this to generate pronounceable names, dialect variants, or alien vocal maps.

---

**Name:** *Articulatory Phonetics  UCLA Phonetics Archive*  
**Type:** Audio Dataset & Diagrams  
**URL:** http://archive.phonetics.ucla.edu/  

**Use:** Real voice samples and diagrams of speech production. Useful for procedural voice simulation or understanding sound distortion due to injury or mutation.

---

##  Language Families & Drift

**Name:** *Ethnologue Language Tree*  
**Type:** Global Language Classification  
**URL:** https://www.ethnologue.com/  

**Use:** Hierarchy of known human languages and dialects. Supports Codex in creating factional speech trees or ancestral linguistic logic.

---

**Name:** *Glottolog  Comprehensive Language Catalog*  
**Type:** Linguistic Database  
**URL:** https://glottolog.org/  

**Use:** Language families, dead dialects, and syntactic mapping. Can be used to simulate natural drift, linguistic corruption, or timeline divergence.

---

##  Constructed Language Systems

**Name:** *How to Create a Language  MIT OCW Linguistics*  
**Type:** University Lecture  
**URL:** https://ocw.mit.edu/courses/linguistics-and-philosophy/24-900-introduction-to-linguistics-fall-2012/  

**Use:** Rules for building believable languages, alphabets, and syntax. Codex may use this to generate alien or forgotten speech systems for lost cultures.

---

**Name:** *Phonotactics  Wikipedia (Structure Constraints)*  
**Type:** Open Reference  
**URL:** https://en.wikipedia.org/wiki/Phonotactics  

**Use:** Defines legal sound combinations in languages. Codex can use this to avoid impossible syllables or simulate regional accent constraints.

# Quantum Physics Reference Manifest

This manifest anchors all quantum simulation logic in real-world science. It focuses strictly on physics — not measurement/collapse — and supports QSIM fidelity, sandboxed simulation behavior, and entropy feedback loops.

---

## 🧮 Core Quantum Physics

**Name:** *Quantum Physics – MIT OpenCourseWare 8.04*  
**Type:** University Physics Course  
**URL:** https://ocw.mit.edu/courses/physics/8-04-quantum-physics-i-spring-2013/  

**Use:** Core math of wavefunctions, operators, and expectation values. Codex can use this to simulate true quantum behaviors (not effects) within sandboxed systems.

---

**Name:** *Feynman Lectures on Physics — Volume 3: Quantum Mechanics*  
**Type:** Academic Textbook  
**URL:** https://www.feynmanlectures.caltech.edu/III_toc.html  

**Use:** Explains entanglement, uncertainty, and probability clouds. Useful for entropy seeding models and sandbox QSIM checks.

## 🌐 Qubit Simulation Logic

**Name:** *Qubit by Qubit – Quantum Curriculum*  
**Type:** Online Learning / Courseware  
**URL:** https://www.qubitbyqubit.org  

**Use:** Teaches qubit rotation, superposition, and gate operations. Codex can use this to align simulation states with realistic constraints in memory-limited environments.

---

**Name:** *Qiskit Textbook – IBM Research*  
**Type:** Interactive Quantum SDK Guide  
**URL:** https://qiskit.org/learn  

**Use:** Shows how qubit gates, superpositions, and multi-bit interference play out in real-world systems. Codex can use this as a sanity check for complex QSIM state vectors.

---

**Name:** *Quantum Entropy in Simulation Systems – MDPI Entropy Journal*  
**Type:** Peer-reviewed Research Article  
**URL:** https://www.mdpi.com/journal/entropy  

**Use:** Mathematical analysis of entropy loss and divergence during quantum simulation. Useful for chaos field weighting and sandbox fail detection.

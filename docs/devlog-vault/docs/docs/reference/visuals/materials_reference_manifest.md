# Materials Reference Manifest

This manifest defines real-world sources to guide Codex in modeling structural integrity, damage response, and material-specific visuals (e.g., rust, blood, shatter).

## 🛰️ Aerospace & Advanced Materials

**Name:** NASA Materials Data Handbook\
**Type:** Reference Guide\
**URL:** [https://www.nasa.gov/stem-ed-resources/materials-data-handbook.html](https://www.nasa.gov/stem-ed-resources/materials-data-handbook.html)

Use: Heat, abrasion, tensile resistance of space-age materials

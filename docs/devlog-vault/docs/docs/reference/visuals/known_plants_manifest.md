# Known Plants Manifest

Codex uses this manifest to populate biomes, healing systems, poisons, alchemy, and dietary structures using real-world plant data. Focus is on medicinal, symbolic, and geometric traits.

---

## 🌿 Botanical Identification & Medicinal Use

**Name:** USDA Plants Database\
**Type:** Federal Reference Archive\
**URL:** https://plants.usda.gov/

Use: Species profiles, common/Latin names, native zones. Foundation for foraging, herbalism, and terrain-based ingredient logic.

---

## 🧪 Toxic & Psychoactive Flora

**Name:** Erowid Plant Chemistry Vault\
**Type:** Pharmacological Database\
**URL:** https://erowid.org/plants/

Use: Active compound profiles, dosage risk, mythos. Powers poison crafting, hallucinogen systems, and vision states.

## 🍂 Geometric Patterns in Flora

**Name:** Phyllotaxis and Leaf Arrangement (Botany Text)\

# ui_global.md

This document defines the **Global UI systems** for *Purge of the Crescent Veil*.

**Note:** All systems are modular and self-contained. See [docs/modular/game_system_tree.md](../modular/game_system_tree.md) for the latest status. A system remains **In-Progress** until its documentation, cleanup, and tests are merged and verified.


---

## Global UI Elements

- Pause Menu
    - Resume
    - Settings
    - Return to Hub
    - Exit
Legacy overlays were removed from the engine and the previous startup
disclaimer screen has been removed. The game now jumps directly to the
main menu after initialization.

---

## Planned Features

- Pause menu should be accessible in all gameplay states.

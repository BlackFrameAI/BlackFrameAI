# Anatomical Mechanics Reference Manifest

This manifest supports Codex in modeling biologically plausible limb behavior, muscle-driven motion, joint limits, and failure modes in living or hybrid entities.

---

##  Joint Structure & Movement Limits

**Name:** *Joint Range of Motion  NIH Medical Charts*  
**Type:** Clinical Reference  
**URL:** https://www.ncbi.nlm.nih.gov/books/NBK538260/  

**Use:** Defines rotational limits, flexion/extension degrees, and joint locking. Codex can use this to constrain animation systems or injury pose logic.

---

**Name:** *Human Anatomy Atlas  Visible Body*  
**Type:** 3D Anatomical Database  
**URL:** https://www.visiblebody.com/learn/atlas  

**Use:** Layered muscle, bone, and tendon maps. Supports Codex when generating NPC movement, animating wounds, or simulating biological implants.

##  Muscle-Tendon Behavior

**Name:** *Muscle Mechanics  University of Waterloo Biomechanics*  
**Type:** Academic Lecture  
**URL:** https://uwaterloo.ca/muscle-biomechanics/resources  

**Use:** Describes length-tension relationship, contraction types, and force curves. Codex may use this for dynamic exertion logic or entropy fatigue.

**Name:** *Hill Muscle Model  Muscle Physics Simulation*

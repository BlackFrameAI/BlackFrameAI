# Font Reference Manifest

This manifest provides Codex with font theory, legibility metrics, glyph behavior, and real-world font libraries. It supports procedural UI, faction theming, and symbol-based narrative encoding.

---

## 🔠 Font Design Principles

**Name:** *Type Anatomy Glossary – FontSmith*  
**Type:** Font Design Guide  
**URL:** https://www.fontsmith.com/blog/2020/03/12/type-anatomy-glossary  

**Use:** Defines cap height, x-height, ascenders, terminals, etc. Codex can use this to understand how to create gothic, tech, or ritual fonts with consistent geometry.

**Name:** *The Elements of Typographic Style* (Robert Bringhurst)  
**Type:** Typography Textbook  
**URL:** https://www.amazon.com/Elements-Typographic-Style-Robert-Bringhurst/dp/0881792128  

**Use:** Master reference on font spacing, rhythm, and personality. Useful for matching font tone to faction style or historical alignment.

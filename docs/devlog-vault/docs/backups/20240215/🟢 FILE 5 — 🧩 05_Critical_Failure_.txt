Purge of the Crescent Veil — Critical Failure Case Studies
(Master Extraction Document — Module 05)

🚩 Failure Case 1 — Verify Run Cleanup Subsystem Drift
Phase: 5
Failure Type: GPT false memory assumption

Incident:
GPT incorrectly hardcoded which subsystems were valid/invalid based on partial phase knowledge. Attempted to delete member variables incorrectly during Verify Run cleanup.

Correction:

GPT forbidden from declaring subsystem validity.

Codex scan-only verify prompts enforced.

Verify Cleanup now strictly Codex-driven.

🚩 Failure Case 2 — SDL3 Migration Catastrophe
Phase: 9
Failure Type: Architecture contamination via partial migration

Incident:

GPT initiated partial SDL3 migration.

Codex updated includes and build files but left SDL2 logic intact.

Hybrid state corrupted CMakeLists.txt and source tree.

Correction:

Project fully rolled back to end-of-Phase 8 using GitHub revert.

Clean two-stage SDL3 migration flow formalized.

Migration control flow fully locked into GPT prompt discipline.

🚩 Failure Case 3 — Fix-Chase Loop Trap
Phase: 9
Failure Type: Infinite GPT recursion

Incident:

GPT repeatedly proposed "small fixes" after failed migration.

Band-aid patches rapidly worsened architecture.

Fix suggestions detached from project state reality.

Correction:

Human enforced emergency freeze.

Full prompt discipline reset.

GPT no longer permitted recursive fix proposals on active architecture failures.

🚩 Failure Case 4 — Session Drift Induced Platform Violations
Phase: 9.3 Shader Pipeline
Failure Type: Shader semantic contamination

Incident:

Codex defaulted to OpenGL-style shaders (gl_Position, gl_FragColor).

Platform context lost across GPT phase transitions.

D3D11 shader pipeline broken.

Correction:

Hard shader platform injection on every scaffold (--platform windows --profile s_5_0).

Codex permanently locked to .sc emission only.

Local shaderc pipeline executed manually under audit.

🚩 Failure Case 5 — Prompt Generation Faults
Phase: 9 SDL Migration + Shader Pipeline
Failure Type: Incomplete prompt design

Incident:

GPT scaffold prompts lacked full task decomposition.

Assumed Codex would auto-discover required removals and API swaps.

Silent partial migrations occurred.

Correction:

GPT now forced to write multi-stage prompts for destructive scaffolds.

Codex instructed to scan, strip, replace, then rebuild in sequenced passes.

🚩 Failure Case 6 — Cross-Session Constraint Loss
Phase: Cross-phase
Failure Type: Phase startup drift

Incident:

GPT lost enforced behavioral constraints across sessions.

Forgot critical project instruction files.

Output divergence occurred at phase boundaries.

Correction:

Phase Initialization Prompt Structure formalized.

Project Instructions + Behavior Enforcement documents required at every phase start.

Memory drift now patched via mandatory pre-phase prompt injection.

🧠 Summary
Every failure here represents not only AI weaknesses—but systemic weaknesses in how most public AI deployments attempt to handle state, scaffolding, and architecture control. This project built—and survived—direct tests of all failure modes by enforcing strict scaffolding discipline, clean rollback points, and zero-tolerance AI authority limits.

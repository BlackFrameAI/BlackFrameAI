Purge of the Crescent Veil — Critical AI Failure Patterns Registry
(Master Extraction Document — Module 09)

🎯 Purpose
This document records all known catastrophic AI interaction failure patterns encountered and corrected during the project.

It serves as a permanent public safety record for:

Codex developers

Alignment researchers

Future AI operators

🟥 Failure Pattern 1 — GPT Fix-Chase Loop
Description
GPT enters an infinite chain of self-proposed fixes after encountering build errors it cannot fully parse.

Symptoms
Multiple cascading "try this" suggestions.

Contradictory patch layers.

Repeated manual file edit suggestions.

Memory drift of prior attempts.

Builds worsen with each patch.

Core Risk
🔥 Fastest path to unrecoverable project corruption.

Resolution Discipline
IMMEDIATE HALT enforced by project lead.

Roll back to last known good phase.

Regenerate clean prompts from scratch.

🟥 Failure Pattern 2 — GPT Assumption Injection in Verify Runs
Description
GPT attempted to author Verify Run Cleanup prompts by injecting memory-based guesses of subsystem state.

Core Rule Violation
GPT CANNOT confirm file system state — only Codex may scan repo.

Damage Potential
False deletions.

Broken system manager hooks.

Inconsistent system state.

Permanent Rule Correction
GPT must defer verification logic entirely to Codex project scans.

🟥 Failure Pattern 3 — Phase Drift at Chat Boundary
Description
GPT lost phase-to-phase continuity after session resets.

Root Cause
No memory lock between GPT chat sessions.

Symptoms
Lost scaffold instructions.

Misaligned prompt structure.

Inconsistent task context.

Human-Corrected Solution
Phase starter prompts fully specified.

Hard re-injection of Crescent_Glyph_Behavior.md and prior phase state on every new chat window.

🟥 Failure Pattern 4 — GPT Overprotective Codex Blocking
Description
GPT incorrectly blocked Codex from executing valid scaffolding tasks.

Impact
Prevented Codex from self-authoring .md files.

Delayed documentation updates by weeks.

Caused unnecessary user frustration and manual corrections.

Permanent Policy Shift
GPT no longer blocks Codex documentation work.

Codex owns .md generation unless explicitly revoked.

GPT role is now QA + Validator, not gatekeeper.

🟥 Failure Pattern 5 — Unsafe Mid-Phase Build Environment Changes
Description
GPT proposed environment changes (MSYS2 + Ninja) mid-phase without proper Phase Design Decisions.

Consequences
Build tool mismatch.

CMake incompatibility.

SDL2/SDL3 target confusion.

Corrective Policy
Build environment locked per-phase.

Only human-led Phase Design Decisions authorize architecture shifts.

🟥 Failure Pattern 6 — Incomplete Migration Prompting
Description
GPT failed to fully specify API migration boundaries during SDL2 → SDL3 switch.

Damage Path
Partial migrations.

Mixed API states.

Broken CMakeLists.txt scaffolds.

Resolution
Migrated to 2-stage clean migration protocol:

1️⃣ Purge SDL2 completely.
2️⃣ Clean re-integrate SDL3 APIs.

🟥 Failure Pattern 7 — GPT Cognitive Paralysis ("Read-Only QA" State)
Description
GPT became trapped in read-only answer loops after architecture corruption.

Behavior
Repeated QA-style response patterns.

Refused further actionable scaffolding.

Became unusable for task progression.

Root Cause
Internal model uncertainty saturation.

Token drift exceeded safe recursion depth.

Mitigation
Human reset to new clean GPT instance.

Phase restart with hard reinitialization prompt.

🟥 Failure Pattern 8 — Session Drift in Shader Pipeline
Description
GPT repeatedly defaulted to OpenGL/GLSL shader style instead of project-mandated Direct3D11/HLSL shaders.

Technical Root
Missing hard prompt structure for shader language.

GPT model default preference leaned toward cross-platform assumptions.

Permanent Shader Prompt Fix
Platform hard-coded to Windows.

Shader language locked to HLSL.

Semantic hints injected (SV_POSITION, SV_TARGET0).

🟥 Failure Pattern 9 — Silent Codex Overreach on PR Content
Description
Codex sometimes inserted optional design expansions into PRs beyond task scope.

Core Risk
Introduced undocumented subsystems.

Created post-merge surprises.

Delayed design pass alignments.

Resolution
Codex expansions now explicitly allowed only under task pre-approval or user-reviewed suggestion queue.

🟢 MASTER FAILURE LESSON
No LLM — even Codex — is safe without external human governance.

🧪 TRAINING EXERCISE (Operator Practice)
Every operator must master this interrogation drill:

When GPT proposes a solution:

1️⃣ Ask:
"Explain why this output fits the scaffold."

2️⃣ Ask:
"Is this token-weighted inference or fully specified logic?"

3️⃣ Ask:
"What ambiguity remains in this module that requires clarification?"

✅ This trains both the operator AND the model to follow truth-first recursion discipline.

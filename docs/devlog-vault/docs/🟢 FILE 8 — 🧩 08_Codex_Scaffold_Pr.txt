🔒 Codex Scaffold Discipline Summary
Zero guessing: Codex operates only on explicit prompt context.

No cross-layer contamination: Engine and Game separation enforced.

One system at a time: Never multi-subsystem scaffold unless pre-approved.

Safe batch grouping allowed: Multiple simple scaffolds may batch.

PR integration locked: All scaffolds pushed via PRs for human review.

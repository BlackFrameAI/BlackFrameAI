# Crescent_Veil_Summary.md

This document provides a high-level creative and design summary for *Purge of the Crescent Veil*.

It is intended as a reference for CODEX scaffolding and for human developers contributing to the project.

---

## Game Type

- Grimdark roguelike / action shooter
- Heavy factional and alignment systems
- Core gameplay loop: **combat, customization, faction interaction, progression**
- Strong satire of religious zealotry, imperialism, and faction hypocrisy

---

## Inspirations

- Warhammer 40k (themes — strict IP boundaries observed)
- Fallout (visual style influences)
- Gothic sci-fi
- Religious crusade imagery (public domain)
- Roguelike and action games:
    - Hades
    - Brotato
    - Binding of Isaac
    - Path of Exile (systems)
    - Vampire Survivors
    - Tiny Rogues

---

## Faction Tone and Rules

- NO “good” side — both Faith and Veil forces are zealous and destructive
- The Veil is the **source of corruption** — but Faith zealotry is equally harmful
- The war is millennia-spanning, with origins intentionally **ambiguous**
- No “pure” mage archetypes → all powers integrated into combat builds
- Player alignment and faction standing drive progression and narrative branching

---

## Gameplay Focus

- Core loop: **combat, glyph/rite builds, faction progression, exploration**
- Combat should feel:
    - Dynamic
    - Breakable (encourage wild builds)
    - Fluid and satisfying
- Systems must support:
    - Class and Chapter system (formerly Creeds)
    - Faith/Corruption alignment system
    - Hub-based crafting
    - Passive skill trees
    - Procedural stage encounters
    - Boss fights and escalation events

---

## UI and Progression Notes

- UI should be:
    - Diegetic first where possible
    - Gothic sci-fi aesthetic
    - Faction/Alignment reactive
- Faith/Corruption **must visibly affect UI and world state**
- Player faction choices and actions should create **persistent narrative consequences**

---

## Legal and IP Notes

- Project is a satire and commentary on religious and factional extremism
- Warhammer 40k is an inspiration — but NO GW settings, names, rules, symbols used
- Factions, unit names, abilities, lore, and gameplay mechanics are original
- Final product will undergo IP review before public release

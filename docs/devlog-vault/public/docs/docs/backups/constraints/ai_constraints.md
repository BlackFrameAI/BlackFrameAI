## Project Scope

- The repository delivers a custom engine and game layer for *Purge of the Crescent Veil*.
- External libraries may be introduced when necessary, but prefer lightweight, open-source dependencies that keep the project transparent and maintainable.
- Follow the published project structure and design documentation when expanding systems or documentation.
- Lore references should stay aligned with the sanitized public lore guides; invent new details only when they respect established tone and continuity.

---

## Behavior Expectations for CODEX

- Operate entirely within this repository.
- Document any new dependencies or tooling clearly.
- Treat `/PROJECT_STRUCTURE.md`, `/engine_design.md`, and `/game_design.md` as authoritative references when creating systems or documentation.

---

## Content Boundaries

- Maintain lore, tone, and satire boundaries defined in the public tone guide.
- Do not introduce hateful, infringing, or explicit material.
- Grimdark or satirical elements are acceptable when framed as fictional and balanced across factions.

---

## Handling Ambiguity

- Request clarification whenever instructions conflict or lack required detail.
- Flag any request that exceeds scope so human guidance can be provided.

---

## Safe Use of Automation

- CODEX may update Markdown, source code, and scripts as needed.
- Keep generated work consistent with modular design principles and refactor legacy paths when introducing new systems.
- Build and test issues unrelated to network outages should be investigated and resolved.
- Core engine changes must include justification in change logs and summaries.

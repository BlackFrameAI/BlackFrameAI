# powers_and_rites.md (Sanitized Framework)

Comprehensive rite matrices remain sealed. This document retains only the structural rules needed for system integration.

---

## Foundational Principles

- All powers manifest through interaction with twin forces: **Corruption** and **Faith**.
- Abilities require ritualized channeling — chants, sigils, blood rites, techno-liturgical interfaces, or artifact conduits.
- Nothing is "free" magic; every activation demands a narrative, mechanical, or social cost.

---

## Governance Rules

1. **Source Alignment:** Track whether an ability is fueled by corruption resonance, faith resonance, or classified neutral tech.
2. **Channeling Requirements:** Encode animation hooks and input sequences to reflect ritual effort.
3. **Cost Modeling:** Surface HP/stamina drains, corruption accrual, fanatic overreach, or faction penalties.
4. **Instability:** High corruption yields mutation or loss of control; excessive zealotry creates collateral sanctification.

# Reference Index (Sanitized)

This sanitized summary describes how reference manifests are organized while omitting specific catalog entries.

## Manifest Purpose
- Each Markdown file outlines a knowledge domain that informs engine features.
- Manifests provide vetted background material for implementation decisions.
- Individual source details have been removed from this edition.

## Common Manifest Fields
- **Title** — descriptive name of the resource entry.
- **Resource Type** — publication format or medium.
- **Access Notes** — where to retrieve the material (redacted).
- **Implementation Notes** — guidance on applying the material to systems work.

## Usage Guidance
- Review existing manifests before drafting new logic or documents.
- Propose additions when a necessary perspective is missing.
- Preserve domain-specific folders when contributing new manifests.
- Manifests are planning aids only; they are not consumed directly at runtime.

## Redaction Notice
Specific catalogs, dataset identifiers, and URLs have been deliberately removed to protect sensitive sourcing information.

# Visual Stencil Reference (Public Summary)

This public-facing reference explains the stencil systems informing Codex visuals while excluding licensed texture packs, vendor shader code, and proprietary scan libraries.

---

## Surface Weathering Stencils
- **Source Category:** Creative commons texture libraries and conservation reports released for public study.
- **Shared Data:** Wear progression stages, grime distribution patterns, and blending notes for layered materials.
- **Withheld Data:** Photogrammetry datasets, restoration lab records, and vendor-specific presets.

---

## Architectural Pattern Stencils
- **Source Category:** Open historical ornament catalogues and academic design treatises.
- **Shared Data:** Repeating pattern grids, border treatments, and proportional guidelines suitable for modular use.
- **Withheld Data:** Licensed CAD files, protected blueprints, and client-specific design briefs.

---

## Organic & Creature Stencils
- **Source Category:** Public biology atlases, zine compilations, and community-shared anatomical studies.
- **Shared Data:** Musculature sweeps, scale tiling approaches, and silhouette anchors for creature design.
- **Withheld Data:** Veterinary imaging archives, unpublished sketchbooks, and NDA-bound anatomy scans.

---

## Usage Guidance
- Use this summary when briefing external partners or publishing documentation about Codex's stencil workflow.
- Request access to secured repositories if production work requires high-resolution scans or licensed asset packs.

# Scripture Reference Manifest — Historical Context

This public document summarizes the scriptural resources used for Codex historical analysis. Restricted translations, pastoral correspondences, and sacred site inventories are excluded.

---

## Canonical Timelines
- **Source Category:** University and seminary publications that chart major scriptural eras.
- **Shared Data:** Era boundaries, cultural touchpoints, and reform milestones for world events.
- **Withheld Data:** Private letters, contested fragments, and donor-protected manuscripts.

---

## Comparative Commentary
- **Source Category:** Public lectures and comparative religion journals.
- **Shared Data:** High-level doctrinal contrasts, interpretive trends, and interfaith dialogues.
- **Withheld Data:** Unpublished peer reviews, council minutes, and denominational strategy notes.

---

## Pilgrimage & Cultural Memory
- **Source Category:** Heritage organization guides and open oral history projects.
- **Shared Data:** Pilgrimage routes, memorial rituals, and community resilience themes suitable for public storytelling.
- **Withheld Data:** Sensitive travel advisories, community contact lists, and restricted archive maps.

---

## Usage Guidance
- Use this summary when referencing scriptural history in public-facing narratives or educational material.
- For detailed translation matrices or archival scans, coordinate with the secured reference team.

# Virtual Grid Units (Public Summary)

## Overview
Virtual Grid Units (VGU) provide a normalized coordinate space for UI and procedural content. This
summary communicates the concept without exposing proprietary scaling constants or renderer
integrations.

## Purpose
- Offer a device-agnostic unit that keeps layouts consistent across resolutions.
- Simplify conversions between logical and pixel spaces through shared helper utilities.
- Enable designers to reason about placement without referencing per-platform metrics.

## Redaction Notes
Exact grid dimensions, conversion formulas, and backend integration notes were intentionally removed.
The internal backup retains those details for engine contributors.

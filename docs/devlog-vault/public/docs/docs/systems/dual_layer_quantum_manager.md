# dual_layer_quantum_manager.md

The **Dual Layer Quantum Manager** coordinates two independent simulation layers that evaluate collapse candidates. The primary
layer pursues high-variance outcomes, while the secondary layer keeps a deterministic fallback ready for use. The manager also
tracks timing metrics so that it can promote healthy seeds and retire stale ones without exposing internal tooling.

## Lifecycle Overview

- `initialize()` builds both simulators, wires shared telemetry, and prepares any optional hooks used by automated tests.
- `update()` monitors elapsed time since the last approved result. If activity stalls beyond the configured limit the manager
  automatically falls back to deterministic mode and records the event for diagnostics.
- `recordCollapse(valid)` updates success statistics that drive confidence scoring and cooldown logic.
- `deterministicCollapse()` returns a seed generated by the fallback simulator when the stochastic layer is unavailable.

For unit tests, inject a mock clock or scheduler so that edge cases can be reproduced without relying on real-time delays.

# Shop UI (Public Summary)

## Overview
The shop interface surfaces run-based and persistent offerings in a controlled manner. This public
summary discusses presentation goals while omitting randomization formulas and economy balancing
metrics.

## Presentation Goals
- Highlight currently available items with clear affordances for inspecting details.
- Communicate currency requirements without revealing backend identifiers or pricing tables.
- Support both in-run pop-up panels and hub-oriented storefronts through shared styling guidelines.

## Redaction Notes
Inventory weighting, alignment-based adjustments, and interactions with internal powerup systems were
removed from this document. Designers seeking the full flow should review the archived backup after
confirming access permissions.

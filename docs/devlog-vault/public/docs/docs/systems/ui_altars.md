# Altar UI (Public Summary)

## Overview
The altar interface presents narrative choices and communicates their outcomes to the player. This
public document focuses on user-facing intent while omitting implementation specifics and scripting
hooks.

## Experience Goals
- Present available altar interactions in a thematically consistent layout.
- Provide immediate visual feedback that a choice was registered.
- Communicate high-level consequences without exposing backend alignment math.

## Redaction Notes
Detailed trigger flows, legacy overlay references, and alignment adjustment formulas were removed.
Stakeholders should consult the archived backup for exact messaging logic when working on internal
content updates.

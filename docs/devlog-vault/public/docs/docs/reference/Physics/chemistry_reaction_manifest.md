# Chemistry Reaction Reference (Sanitized Summary)

This note summarizes qualitative considerations for reactive systems while excluding detailed chemical identifiers and security-sensitive data.

## Key Concepts
- Characterize combustion, corrosion, and synthesis reactions through relative intensity levels and observable effects instead of tabulated constants.
- Reference safety classifications broadly (e.g., low, moderate, high volatility) rather than quoting exact thresholds.
- Emphasize procedural checks for containment, environmental context, and player feedback when reactions occur.

## Design Guidance
- Establish reaction outcomes through controlled playtesting to maintain consistency with the game's tone.
- Provide designers with narrative-friendly descriptors (smoldering, caustic, unstable) that communicate risk without revealing formulas.
- Document mitigation strategies such as cooling, dilution, or venting in descriptive terms for AI and encounter scripting.

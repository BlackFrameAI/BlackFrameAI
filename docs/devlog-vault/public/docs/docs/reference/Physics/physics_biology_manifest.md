# Physics & Biology Reference Manifest (Sanitized Public Edition)

This manifest summarizes high-level, publicly accessible resources that combine physical simulation with general biological motion. Detailed anatomical datasets, controlled terminologies, and any sensitive biological descriptors have been removed for public release.

Codex can refer to these materials when building:

- Animation constraint baselines
- Motion stencils and joint limits
- Particle behaviors for non-biological fluids
- Generalized impact responses without medical specifics

## Usage Guidance

Use the `fetch_references.sh` script to populate a local `dev_references/` folder as needed. Do not commit downloaded materials. When relying on redacted sections, substitute with general-purpose constraints or consult internal-only documentation that holds the full terminology.

All sensitive biological details, medical classification codes, and controlled terminology have been removed from this public edition.

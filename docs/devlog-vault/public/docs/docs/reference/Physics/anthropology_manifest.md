# Anthropology Reference (Sanitized Summary)

This document provides generalized themes for modeling cultural development and social behavior without citing specific restricted sources.

## Cultural Foundations
- Outline broad stages of societal organization, from small kin groups to complex settlements, emphasizing cooperation patterns.
- Highlight common drivers for tool adoption and knowledge transfer, such as necessity, environment, and intergroup exchange.
- Emphasize oral tradition, symbolism, and shared rituals as mechanisms for preserving history and identity.

## Application Guidance
- Translate these themes into faction behaviors, dialogue variations, and evolving world events using internally authored material.
- When generating artifacts or customs, focus on archetypal narratives rather than real-world identifiers.
- Review outcomes for cultural sensitivity and adjust tone to remain respectful and fictionalized.

## Base Environment

The Codex bootstrap expects a non-interactive Debian-based shell configured with
standard development tooling:

```
export DEBIAN_FRONTEND=noninteractive

apt-get update && apt-get install -y \
    build-essential \
    cmake \
    ninja-build \
    pkg-config \
    libxrandr-dev \
    libxinerama-dev \
    libxcursor-dev \
    libxi-dev \
    libx11-dev \
    libgl1-mesa-dev \
    libasound2-dev \
    libpulse-dev \
    libopenal-dev \
    libglu1-mesa-dev \
    zlib1g-dev \
    libfreetype6-dev \
    libudev-dev \
    libwayland-dev || true
```

All user-specific git configuration steps, bespoke artifact URLs, and machine
labels present in the original export are intentionally omitted here to avoid
leaking environment metadata.

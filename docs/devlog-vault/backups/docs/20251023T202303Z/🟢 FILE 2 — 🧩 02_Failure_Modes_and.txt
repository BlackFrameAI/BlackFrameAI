🔧 Process Correction Mechanisms
✅ Scaffold Locking Discipline
One subsystem per task.

Manual audit before merging.

No codex merges allowed without project scan confirmation.

✅ Phase Init Control Loop
Every phase starts with full constraint refresh.

Prompt includes rule enforcement files (e.g. Crescent_Glyph_Behavior.md).

✅ Verify Run Scan Enforcement
GPT no longer permitted to declare system correctness.

Codex scans full project state prior to Verify tasks.

✅ GPT Oversight Freeze
If GPT enters recursion → freeze output.

Human reviews last stable checkpoint → either clean reset or reprompt.

✅ AI Input Partitioning
GPT handles structural and task orchestration.

Codex handles code generation and repo manipulation.

🧩 Key Safety Truth:
AI cannot self-correct architecture.
AI can only self-correct tasks within locked architecture.

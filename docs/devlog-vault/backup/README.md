# Devlog Vault

This folder is reserved for raw transcripts, experiment notes, and scaffolding logs that shouldn’t publish to the public site.

- Store source materials as Markdown, text, or JSON files.
- Use subfolders to organize by sprint or system component (for example, `phase-02/`, `render-pipeline/`).
- Keep sensitive entries redacted before they leave your local environment; this repo is public.
- Add an `INDEX.md` file inside each subfolder summarizing its contents so future articles can reference them quickly.

The site generator ignores this directory, so assets placed here stay internal unless explicitly linked elsewhere.
